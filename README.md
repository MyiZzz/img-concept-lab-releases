## 使用

下载 exe 后双击打开。关闭窗口或选择「文件 → 退出」即可结束。无需安装 Node、Python 或 MATLAB，也无需管理端口。

课程、内置图片、公式和实验可以离线使用。阅读位置与练习答案保存在本机 `%APPDATA%\ImageConceptLab`；备份前请先退出程序，再复制整个目录。
